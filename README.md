Student lab guides for the PMI Data Analyst Future Skills class (Project HORIZON, fictional and training-only): a start page, one page per session (WA3899 · WA3900 · WA3901 · WA3902) and a glossary.
Live at https://varoonsahgal.github.io/pmidataanalyst-labs/ (GitHub Pages serves this folder as-is; `.nojekyll` keeps Jekyll out of it).
The pages are built from `_src/pages/*.html` by `python3 _src/build.py` (art in `_src/art.py`, charts in `_src/charts.py`; needs Pillow). Every number in the guides was run against the HORIZON warehouse.
To view locally, run `python3 -m http.server 8000` in this folder and open http://localhost:8000/.

**Instructor guides** (`instructor.html` hub, `instructor-s1.html` to `instructor-s4.html`) are built by the same script from `_src/pages/i0.html` to `i4.html`, with `assets/guide.css` on top of `site.css`. Each one teaches its lab from zero (no SQL, PMI or marketing knowledge assumed) in about 18 minutes of reading: the point, the business and tech words, the data drawn with real rows, the traps, every step walked (students do / they see / it means / you say), then a timed run of show, rescue table, dry run, likely questions and a 60-second recap. Extra build tags: `<lane do|see|mean|say|you|watch>` and `<point>`. They carry `noindex` and are not linked from the student pages, but are public to anyone with the URL.
