Group 1

PMI, the program and the markets

PMI
Philip Morris International.
Smoke-free products
Products without combustion: heated tobacco (IQOS), e-vapor (VEEV), oral nicotine (ZYN). 41.5% of PMI's net revenues in FY2025.
IQOS
PMI's heated-tobacco device brand.
VEEV
PMI's e-vapor brand. A device.
ZYN
PMI's oral nicotine pouch. Not a device.
DI&A
PMI's data function and the sponsor of the Future Skills program.
CoP
Community of Practice. The DI&A CoP Leads selected the four skills.
IDP
Individual Development Plan. Add the four skills to it with your Line Manager.
JP · IT · ID
Japan (mature, regulator MHLW) · Italy (mid-adoption, EU, AAMS/EU) · Indonesia (early-stage, BPOM).
MHLW · AAMS/EU · BPOM
Japan's Ministry of Health, Labour and Welfare · Italy's customs and monopolies authority plus EU rules · Indonesia's National Agency of Drug and Food Control.
Adult consumer
PMI's standard phrasing: smoke-free products are for adults who would otherwise continue to smoke.
Conversion
In PMI usage, an adult smoker switching to a smoke-free product. In HORIZON, lifecycle_stage = 'conversion'.
Age-gate · under-25 rule
A restriction on marketing to an age group. In HORIZON, under-25 marketing isn't allowed in Italy or Indonesia; Japan is different (Session 2 measures it). Real-world legal ages also differ: 20 in Japan, 21 in Indonesia since 2024. HORIZON's single 18-24 band is a training simplification.
Group 2

Project HORIZON

HORIZON
A fictional, training-only PMI data estate. One Postgres database called horizon: three markets, five assets.
CLR
Consumer Lifecycle Records: clr.consumers, clr.lifecycle_events. 6,000 consumers · 15,597 events.
Lifecycle stages
registration → trial → conversion → retention → churn.
MPL
Marketing Permission Ledger: mpl.consent_records. A ledger: several consent rows per consumer over time. 15,052 rows, ~2.5 per consumer.
RST
Retail Sell-Through Feed: rst.sell_through, rst.distributors. Weekly. Never a source for consent. 2,730 rows · 12 distributors.
DET
Device Experience Telemetry: det.device_telemetry. Sessions from connected devices; some rows anonymised by design. 35,113 rows.
RFR
Regulatory Filing Repository: rfr.filings plus rfr.filing_excerpts (unstructured text, a draft signal only). 112 filings · 14 excerpts.
ref.*
Reference tables: ref.markets, ref.products, ref.age_bands, ref.campaigns.
analytics
A sandbox schema. Session 2 writes its synthetic cohort here.
SQLTools
The VS Code extension you use to run SQL. Run a query with Ctrl+E Ctrl+E.
Group 3

SQL and analysis

Schema
The list of tables and columns, or a named folder of tables (clr, mpl).
Grain
What one row represents.
NULL · three-valued logic
NULL means unknown. A comparison with NULL is neither true nor false, and WHERE keeps only true, so campaign_id <> 4 drops every NULL row.
IS DISTINCT FROM
A comparison that treats NULL as a value: campaign_id IS DISTINCT FROM 4 keeps unattributed rows.
Half-open date range
>= start AND < end: a clean, complete window.
DISTINCT
Count each consumer once, however many events they have.
ROLLUP
Adds a total row to a GROUP BY.
Attributed · unattributed
An event tagged to a campaign vs one with campaign_id IS NULL.
Baseline · control group
What a claim is compared against. Without one, "lift" means nothing.
Window
The time period a claim covers.
Population
Who a claim is about.
Independent control query
The same number computed a second, different way.
Percent vs percentage points
13.5% → 21.4% is +7.9 points, or +59% relative. Always say which.
Denominator
The "out of how many" behind a percentage.
Coverage
How much of the population the data actually reaches.
Data-completeness gap
Data that should exist but was never loaded.
Synthetic cohort
A made-up table that imitates a real population, for prototyping.
Provenance
Where a number came from: the check that proved it.
Scenario range
Low / base / high instead of a single forecast point.
Confidence rating
Your judgment of the evidence (1/5 to 5/5), not the model's tone.
Validate · caveat · escalate
It holds · it holds with a stated limit · it's a defect someone must own.
Group 4

AI and prompting

LLM
Large language model: the engine behind Claude.
Token
The word-pieces a model reads and writes, roughly ¾ of an English word. Prices are per million tokens.
Next-token prediction
How an LLM writes: it predicts the next token, over and over, from the text it can see.
Temperature · sampling
How adventurous the next-token choice is. Why one prompt gives different answers.
Context window
Everything the model can see right now: its instructions, your prompt, the chat so far, every tool definition and every tool result.
Context rot
Models get less reliable as the input grows (Chroma tested 18 models in 2025). Start a fresh chat for each new task.
Lost in the middle
Models use the start and end of a long prompt best. Put rules on top and the question last.
Grounding
Giving the model the real facts it needs (schema, rules) so it writes against reality.
Hallucination
A confident, fluent claim that isn't true.
False precision
A precise number computed over data that can't support it.
Sycophancy
A model's tendency to agree with you, even changing a correct answer when you push back.
Few-shot
Showing the model a finished example so it copies the style.
Chain-of-thought
Asking the model to lay out its plan before the answer, so mistakes surface early.
Prompt template
A prompt with labelled {{PLACEHOLDERS}} for the next analyst to fill in.
Model tiers
Opus (premium), Sonnet (middle), Haiku (thrifty): same family, different judgment, speed and price.
Premium planning, thrifty execution
Use the expensive model for the short, judgment-heavy plan and the cheap one for the long, mechanical execution, with a proof step in between.
Model picker
The model name next to the send button in Claude Desktop. You can change it mid-chat; it applies from the next reply.
Project · Claude Desktop
A workspace whose instructions apply to every chat inside it. A good home for your schema and rules.
MCP
Model Context Protocol: an open standard for plugging tools and data into an AI app ("a USB-C port for AI").
MCP client
The app that starts an MCP server and calls its tools on the model's behalf. In Session 4 Part 2: Claude Code.
MCP server
A small program that offers tools. Yours is server.py: four tools over HORIZON.
Tool · MCP
A function a server offers. The model sees only its name, description and input schema, never its code.
Tool poisoning
Instructions hidden in a tool's description. Whoever writes a server writes words into your model's context.
Claude Code
Anthropic's agent for working in files and folders: the Code tab of the Claude app. It is the MCP client in Part 2.
Custom agent
A Claude with its own instructions, its own tools and its own context window, defined in one Markdown file in .claude\agents\.
Least privilege
Give an agent only the tools its job needs. Enforced by its tools list, not by asking nicely.
Prompt hygiene
Everything you paste leaves your data boundary. Schema and rules yes; rows, credentials, connection strings never.
